# tools — инструменты разработки Golem Logix

Ничто из этого не попадает в релизный jar.

## Графика (всё рисуется кодом)

| файл | что делает |
|---|---|
| `ArtForge.java` | точка входа: рисует текстуры первого поколения (ядро, решётка, терминалы, шапки, GUI книги, анимации экранов), вызывает `Models` и `Forge2`, потом `Logo` |
| `Paint.java` | библиотека пиксельной графики: холст в «юнитах блока» (1/16), палитры, скос, зерно, шестерни, манометры, руны, иней |
| `Forge2.java` | второе поколение: шкаф 2×2 (текстуры фасада, боковин, витрины, модели из `BigModel`), динамические текстуры шкафа |
| `BigModel.java` | большая модель в «шкафных» координатах (2x2), которая режется на клетки блоков; `Big3` — то же для 3x3x2 |
| `Buses.java` | три шины: компактное тело, рабочий узел, звезда сверху, разъёмы на каждой стороне, мини-трубки (мультипарт по флагам `north..down`) |
| `Terminals.java` | аналоговый терминал, терминал крафта, кодировщик: фасады, боковины, спинки, крыши и модели с выступами |
| `CabBack.java` | спинка шкафа — одна картина 32x32 и светящийся рельеф |
| `Saturator.java`, `Big3.java` | Насыщатель Маны 3x3x2: фасад/спинка/боковины, детали, нарезка модели на 18 клеток, блокстейты |
| `Pipes.java` | трубы: стекло, пояса, ступица, рукава у устройств, блокстейты |
| `Cassette.java` | одна кассета для шкафа и для иконок дисков предметов |
| `Logo.java` | `logo.png` для списка модов |
| `Models.java` | прочие модели и блокстейты |
| `ModelPreview.java` | офлайн-превью JSON-моделей без запуска игры (`java -cp <out> ModelPreview out.png 0 имя…`) |

Запуск: `powershell -File tools\devshots.ps1 art` (компилирует все `tools/*.java`, кроме `GeneratePdfDocument` и `Audit`, и запускает `ArtForge` из корня проекта).

## Ревизия

`java tools/Audit.java` — ссылки моделей и блокстейтов на текстуры, «осиротевшие» текстуры и модели, размеры текстур не кратные 16
(ограничивают mip-уровни), совпадение ключей перевода ru/en и ключи, на которые ссылается Java.

## Стенд кадров (`gradle runDevShots`)

Клиент (задача `runDevShots`) сам создаёт плоский мир и выполняет текстовые сценарии из `run/devshots/queue/*.txt`. Кадры берутся
из кадрового буфера самой игры (`Screenshot.grab`), экран и ввод операционной системы не затрагиваются; звук выключен.
Код стенда — `src/main/java/com/golemlogix/devtest` (в релизный jar не входит).

Команды сценария (одна на строку, `#` — комментарий):

```
cmd <команда сервера>        выполнить команду от имени игрока (fill, setblock, kill …)
hook <имя> <аргументы>       сборщики сцен и проверки на сервере (array, rig, bay, stock, fillnet, netput, netcheck, netfluid,
                             baycheck, buscheck, give, carry, giveall, mode, refresh, time, saturator, saturatorput, saturatorheld,
                             saturatorcheck)
look x y z дистанция yaw pitch   поставить камеру на расстоянии от точки
cam x y z yaw pitch          поставить камеру точно
wait N                       подождать N тиков
shot имя                     кадр в run/devshots/screenshots/имя.png
reload                       перезагрузить ресурсы (после `gradle processResources`)
use x y z                    правый клик по блоку (откроет окно)
uiclick list индекс|name:часть имени кнопка   клик по списку терминала внутри экрана
slotclick слот кнопка        клик по слоту открытого окна
craftreq предмет количество  заказ автокрафта (как кнопка «Заказать»)
book id [разворот] [раздел]  открыть гримуар на нужной статье
inv / closeScreen            окно инвентаря / закрыть окно
ghost start full|tower|saturator | clear, key Y|N     призрачная стройка и эмуляция нажатия клавиши внутри игры
check имя ожидаемое          проверка на клиенте (carried, inventory, ghostActive, ghostLocked, conflictClicks)
gui on|off, fov N, log текст, quit
```

Результат сценария — `имя.log` рядом (строки `OK …` / `ERR …`). Готовые сценарии лежат в `tools/shots/`
(`e2e1.txt`, `e2e2.txt` — сквозные проверки терминала, автокрафта, шкафа, шины, ведра; `ghost1.txt` — приоритет клавиш Y/N).
Изменение Java-кода требует перезапуска клиента, ресурсов (текстуры, модели, переводы, книга) — только `processResources` и `reload`.
